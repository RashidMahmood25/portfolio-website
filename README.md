# Portfolio Website — Rashid Mahmood

A single-page personal portfolio for Rashid Mahmood, founder of Rust Wheel
(Pakistan's car & bike marketplace, 0% commission).

## Sections

- **About** — who he is and what he's building
- **Rust Wheel** — the marketplace, with app download link
- **Selected Projects** — Rust Tracker, calculators, Markdown Notes, car
  comparison, and open-source contributions (all linked to real repos)
- **Skills** — Python, HTML/CSS/JS, Git & GitHub, Firebase, and more
- **Contact** — GitHub, LinkedIn, Facebook, Play Store links

## How to run

Just open `index.html` in any browser — no build step, no server, no internet
needed (all styling is inline; links point to the live GitHub/Facebook/Play
Store pages).

## What was practiced

- Semantic single-page layout with a sticky nav and responsive cards grid
- Rust Wheel brand colours (Navy #0B1F3A, Blue #1769AA, Cyan #20A4D8)
- Writing honest copy — only verified facts (0% commission, 500+ listings)
